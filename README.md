## ✨ Highlights

- Fully responsive layout (`responsive.css`) with a switchable colour theme.
- About, skills, projects and testimonials sections.
- A Flappy Bird mini-game written in vanilla JavaScript (also published as its own `flappy-bird` repo).

## 🚀 Run it

Open `myportfolio.html` in any browser. No build step is needed.

> 💡 You can host it for free with **GitHub Pages**: go to Settings → Pages → Deploy from branch `main`.
